## Isolation and reproduction

Tests ran from `git archive` exports, with a separate `TMPDIR`, matplotlib
configuration directory, and cache for each repository. `PYTHONPATH` pointed
only to this repository's export (`src`), not all sibling repositories.
The existing scientific virtual environment was reused unchanged.

Run the following only when temporary test writes are authorized, from this
repository's Git checkout. The environment must already contain the recorded
packages; the commands do not install anything. The absolute interpreter path
is specific to the audited Cloud environment and must be mapped explicitly
on another machine.

```bash
set -euo pipefail
SCIENTIFIC_PYTHON=/workspace/.cloud-setup/venv/bin/python
baseline_dir="$(mktemp -d)"
mkdir -p "$baseline_dir/source" "$baseline_dir/tmp" "$baseline_dir/mpl" "$baseline_dir/cache"
git archive 912cf1220f35b42f7c51f9eea8b57ca9f071cc65 | tar -x -C "$baseline_dir/source"
cd "$baseline_dir/source"
env PATH="$(dirname "$SCIENTIFIC_PYTHON"):$PATH" \
  PYTHONPATH="$PWD/src" TMPDIR="$baseline_dir/tmp" \
  MPLBACKEND=Agg MPLCONFIGDIR="$baseline_dir/mpl" \
  XDG_CACHE_HOME="$baseline_dir/cache" PYTHONDONTWRITEBYTECODE=1 \
  PYTHONHASHSEED=0 OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 \
  "$SCIENTIFIC_PYTHON" -B -m unittest discover -s tests -p 'test_*.py' -v
```
